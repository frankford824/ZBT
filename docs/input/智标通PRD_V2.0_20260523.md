## 一、产品概述

### 1.1 产品定位

面向企业投标团队的 B2B 智能标书生成平台，通过 AI 技术实现标讯聚合、标书智能生成、合规检查、项目管理全流程闭环。

### 1.2 核心价值主张

- **提效**：将 3-5 天的标书编制周期压缩至 1-2 天
- **降险**：AI 合规检查降低废标率，覆盖资质、格式、废标条款、语义一致性四重校验
- **沉淀**：企业知识资产持续积累，中标经验可复用

### 1.3 核心功能模块（8个，新增"团队协作"）

1. **工作台** - 数据概览与智能推荐
2. **标讯大厅** - 多平台标讯聚合与智能匹配
3. **标书生成** - AI 分步引导式标书生成（核心模块）
4. **合规检查** - 四重校验体系的智能合规检测
5. **项目管理** - 投标项目全生命周期管理
6. **成本管理** - 中标项目成本追踪分析
7. **知识库** - 企业投标资产智能管理（RAG + 向量检索）
8. **团队协作** - 多人协作、权限管理、审批流程（MVP 后期）

### 1.4 业务流程

```
标讯大厅 → 招标文件解析 → 创建项目 → AI分步生成标书 → 合规检查 → 人工审核 → 提交投标 → 开标结果 → 成本管理
                    ↑                              ↑              ↑
                    |                              |              |
              知识库智能匹配 ←──── 中标案例回流 ←──┘              |
                                                                   |
              团队协作贯穿全流程（审批、评论、@提醒）──────────────┘
```

## 二、竞品分析与差异化定位

### 2.1 竞品格局

| 产品 | 定位 | 核心优势 | 不足 |
|------|------|---------|------|
| 钛投标 | 全行业全流程龙头 | 4重AI校验、跨区域政策适配 | 价格高，中小企业门槛高 |
| 投标无忧 | 企业级深度风控 | "左规右建"双屏、扣分预测 | 偏向大型央国企 |
| 神卷标书 | 中小企业均衡 | WPS集成、5分钟30万字 | 工程领域深度不足 |
| 云境标书AI | 轻量化入门 | RAG降幻觉、免费解析 | 功能相对简单 |

### 2.2 智标通的差异化定位

1. **分步引导式生成**：每一步用户确认后才推进，兼顾效率与掌控感
2. **双库联动**：行业公共模板库 + 企业私有知识库，双库智能匹配
3. **合规检查与编辑器闭环**：发现问题可一键跳转编辑器修复
4. **团队协作原生支持**：从MVP阶段就内置多人协作能力
5. **成本管理深度整合**：中标后无缝衔接成本追踪

### 4.3 标书生成（核心模块 - 重点重新设计）

#### 4.3.1 整体流程设计（分步引导式）

```
Step 1: 项目信息录入
  ├── 标书名称
  ├── 关联项目（下拉选择）
  ├── 上传招标文件（支持 PDF/Word，拖拽上传）
  └── [下一步]

Step 2: 招标文件 AI 解析（新增核心步骤）
  ├── AI 自动解析招标文件（30秒-2分钟）
  ├── 解析结果展示：
  │   ├── 项目基本信息（项目名称、招标单位、预算金额、截止日期）
  │   ├── 资质要求清单（必需资质、加分资质）
  │   ├── 评分标准摘要（技术分/商务分/价格分权重）
  │   ├── 废标条款清单（红色高亮标注）
  │   └── 技术要求摘要
  ├── 用户确认/编辑解析结果
  └── [下一步]

Step 3: 目录大纲生成
  ├── AI 基于解析结果自动生成二三级目录
  ├── 用户可手动调整：
  │   ├── 拖拽排序章节
  │   ├── 添加/删除章节
  │   └── 编辑章节标题
  ├── 评分点章节自动标注（高亮显示评分权重高的章节）
  └── [下一步]

Step 4: 知识库配置
  ├── AI 智能推荐相关素材（基于招标需求匹配）
  │   ├── 企业资质证书（自动匹配需要的资质）
  │   ├── 业绩案例（相似项目案例）
  │   ├── 技术方案（相关技术方案模板）
  │   └── 人员信息（匹配岗位要求的团队成员）
  ├── 用户勾选要引用的素材
  ├── 支持额外上传补充素材
  └── [开始生成]

Step 5: AI 逐章生成（核心交互）
  ├── 生成进度面板：
  │   ├── 当前生成章节（高亮）
  │   ├── 整体进度条
  │   ├── 预估剩余时间
  │   └── 暂停/继续按钮
  ├── 每章生成完成后：
  │   ├── 显示生成内容预览
  │   ├── 用户选择：采纳 / 重新生成 / 手动编辑
  │   ├── 显示引用来源（知识库中的哪个文档）
  │   └── AI 自检提示（该章节是否满足招标要求）
  └── 全部章节生成完成 → [进入编辑器]

Step 6: 标书编辑器（三栏布局，重新设计）
  ├── 左栏：章节大纲树
  │   ├── 可折叠的章节树
  │   ├── 显示每章状态（已生成/待生成/需修改）
  │   ├── 点击跳转到对应章节
  │   └── 合规检查结果标记（警告/失败图标）
  ├── 中栏：内容编辑区
  │   ├── 类 Word 的富文本编辑器
  │   ├── 工具栏：加粗/斜体/下划线/对齐/列表/表格/图片
  │   ├── AI 内联助手：选中文本后弹出操作菜单
  │   │   ├── 优化文字
  │   │   ├── 扩写/缩写
  │   │   ├── 添加技术细节
  │   │   ├── 查找类似案例
  │   │   └── 检查合规性
  │   └── 实时自动保存
  └── 右栏：AI 助手面板
      ├── 招标要求速览（当前章节对应的招标要求）
      ├── AI 对话输入框
      ├── 快速指令按钮
      ├── 引用素材列表（当前章节引用的知识库素材）
      └── 合规检查结果（当前章节的检查项）

Step 7: 导出与提交
  ├── 导出格式选择：Word (.docx) / PDF
  ├── 导出设置：
  │   ├── 排版模板选择
  │   ├── 页眉页脚设置
  │   ├── 目录自动生成
  │   └── 水印设置
  ├── 导出预览
  ├── 提交审批（如开启团队协作）
  └── 提交投标
```

#### 4.3.2 AI 生成准确性保障机制

1. **RAG 检索增强生成**：先检索企业知识库素材，基于真实素材生成内容，降低幻觉
2. **招标文件锚定**：所有生成内容必须关联招标文件中的具体要求，可溯源
3. **引用标注**：生成内容中标注引用来源（知识库文档名称+页码）
4. **自检机制**：每章生成后自动检查是否满足对应招标要求
5. **人工确认门控**：每章生成后必须用户确认才进入下一步
6. **版本对比**：重新生成时显示新旧版本对比，用户可选择保留部分内容

#### 4.3.3 交互元素

- `startGeneration()` - 开始AI生成
- `pauseGeneration()` / `resumeGeneration()` - 暂停/继续
- `acceptChapter(chapterId)` - 采纳章节
- `regenerateChapter(chapterId)` - 重新生成章节
- `editChapter(chapterId)` - 手动编辑章节
- `openEditor(docId)` - 打开编辑器
- `exportDoc(format)` - 导出文档
- `submitForApproval(docId)` - 提交审批

### 4.4 合规检查（重新设计）

#### 4.4.1 四重校验体系

| 层级 | 校验类型 | 说明 | 实现方式 |
|------|---------|------|---------|
| 第一层 | 结构化规则校验 | 资质完整性、签章、格式规范、报价一致性 | 规则引擎 |
| 第二层 | 语义一致性校验 | 条款响应一致性、技术参数匹配、表述矛盾检测 | AI/NLP |
| 第三层 | 废标风险校验 | 废标条款逐条核对、资质到期预警 | 规则引擎 + AI |
| 第四层 | 评分优化建议 | 评分标准逐项核对、扣分风险预测、优化建议 | AI 推理 |

#### 4.4.2 功能清单

- 文件上传区域（支持从标书生成模块直接传入）
- 检查配置面板：
  - 检查范围选择（全文/指定章节）
  - 检查层级选择（可单独或组合启用四重校验）
  - 自定义规则（用户可添加企业内部合规要求）
- 评分概览（大数字 + 环形图）
- 检查结果标签页：
  - 资质要求（第一层+第三层）
  - 格式规范（第一层）
  - 评分标准（第四层）
  - 废标条款（第三层）- 红色高亮
  - 语义一致性（第二层）
- 检查项列表：
  - 通过/警告/失败 三级状态
  - 展开查看详细说明
  - 修复建议（AI 生成）
  - 一键跳转编辑器修复（跳转到对应章节和位置）
  - 一键修复（AI 自动修复简单问题，如格式调整）
- 检查报告导出（PDF/Word）

#### 4.4.3 合规检查与编辑器闭环

- 合规检查发现问题 → 点击"跳转修复" → 打开编辑器并定位到对应章节
- 编辑器中修改后 → 实时更新合规检查状态
- 支持在编辑器中实时合规检查（编辑时右侧面板实时显示当前章节的检查结果）

#### 4.4.4 交互元素

- `startComplianceCheck(docId)` - 开始检查
- `switchComplianceTab(tab)` - 标签页切换
- `toggleCheckDetail(checkId)` - 检查项展开
- `jumpToFix(checkId)` - 跳转编辑器修复
- `autoFix(checkId)` - AI 一键修复
- `exportReport(format)` - 导出检查报告

| 项目管理 | 知识库 | 中标案例自动回流 | 项目信息 + 标书文件 |

## 六、技术实现方案

### 6.1 技术架构

```
前端：React + TypeScript + TailwindCSS + Tiptap（富文本编辑器）
后端：Python FastAPI + Celery（异步任务）
AI 层：
  ├── LLM：GPT-4 / Claude / 国产大模型（通义千问/文心一言）
  ├── RAG：LangChain + 向量数据库（Milvus/Pinecone）
  ├── 文档解析：PyMuPDF + docx + unstructured
  └── 规则引擎：自研 + Drools
存储：
  ├── 关系数据库：PostgreSQL
  ├── 向量数据库：Milvus
  ├── 对象存储：MinIO / S3
  └── 缓存：Redis
部署：Docker + K8s
```

### 6.2 AI 标书生成技术方案

```
1. 招标文件解析
   ├── PDF 解析：PyMuPDF 提取文本 + 表格
   ├── Word 解析：python-docx 提取结构化内容
   ├── 信息提取：LLM + Prompt Engineering 提取关键信息
   └── 输出：结构化 JSON（项目信息、资质要求、评分标准、废标条款）

2. 目录大纲生成
   ├── 基于解析结果 + 行业模板库生成
   ├── LLM 生成二三级目录
   └── 用户确认后锁定

3. 知识库匹配
   ├── 将招标需求向量化
   ├── 在企业知识库向量数据库中检索相似素材
   ├── 按相关度排序，返回 Top-K 结果
   └── 用户确认引用素材

4. 逐章内容生成
   ├── 输入：章节标题 + 招标要求 + 引用素材 + 前文上下文
   ├── RAG 增强：先检索相关素材，再生成内容
   ├── Prompt 模板：包含角色设定、格式要求、引用规范
   ├── 流式输出：SSE 推送到前端实时显示
   └── 自检：生成后自动检查是否满足招标要求

5. 合规检查
   ├── 第一层（规则引擎）：预定义规则清单逐项检查
   ├── 第二层（AI语义）：LLM 判断条款响应一致性
   ├── 第三层（废标风险）：规则 + AI 混合检查
   └── 第四层（评分优化）：LLM 推理扣分风险并给出建议
```

### 6.3 数据安全方案

- **数据加密**：传输层 TLS 1.3，存储层 AES-256
- **数据隔离**：企业间数据逻辑隔离，支持私有化部署
- **访问控制**：RBAC 权限模型
- **审计日志**：全量操作日志记录
- **数据承诺**：不将用户数据用于模型训练
