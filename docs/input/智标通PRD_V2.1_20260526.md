## 一、标讯大厅 - 迭代更新

### 1.1 监控设置 - 数据源管理（重新设计）

#### 问题
当前数据源管理只展示预置平台列表和开关，用户无法添加自己公司经常参与的非预置招标平台。

#### 解决方案

**数据源配置面板重新设计：**

```
数据源管理
├── 预置数据源（平台提供）
│   ├── 中国政府采购网 (ccgp.gov.cn) - 已接入 ✓
│   ├── XX省政府采购网 - 已接入 ✓
│   └── XX市公共资源交易中心 - 未接入
│
├── 自定义数据源（用户添加）
│   ├── 中国招标投标公共服务平台 - 已配置 ✓
│   ├── XX省建设工程交易中心 - 已配置 ✓
│   └── [添加自定义数据源] 按钮
│
└── 数据源状态说明
    ├── 已接入：平台已对接，可自动抓取标讯
    ├── 已配置：用户提供了链接，系统定期检测可用性
    └── 未接入：暂不支持，用户可提交接入申请
```

**添加自定义数据源弹窗：**
- 平台名称（必填）
- 平台网址/URL（必填，需验证格式）
- 平台类型：政府采购 / 建设工程 / 产权交易 / 其他
- 所在地区（省/市选择）
- 账号信息（可选，用于需要登录的平台）：
  - 账号
  - 密码（加密存储）
  - Cookie（用于免登录抓取）
- 抓取频率：实时 / 每小时 / 每天一次
- 备注

**数据源配置逻辑：**
1. 用户添加自定义数据源后，系统先验证URL可达性
2. 系统尝试自动识别页面结构（招标列表页）
3. 如果自动识别失败，提示用户手动标记招标列表的CSS选择器
4. 配置成功后，按用户设定的频率定期抓取
5. 抓取失败的标讯源在列表中显示警告状态

**MVP版本限制：**
- MVP版本只支持"已配置"模式（用户提供链接，系统定期检测）
- 自动抓取功能在MVP后版本实现
- 账号/Cookie登录功能在MVP后版本实现

## 二、标书生成 - 迭代更新

### 2.1 交互深度增强

#### 问题
整体完成度较高，但缺少交互深度：每章生成后缺少明确的"采纳/重新生成/手动编辑"操作入口。

#### 解决方案

**Step 5: AI逐章生成 - 交互增强：**

每章生成完成后，展示以下操作面板：

```
┌─────────────────────────────────────────────────┐
│ 第四章 技术方案                    ✅ 生成完成     │
├─────────────────────────────────────────────────┤
│                                                   │
│  [生成内容预览区域]                                │
│                                                   │
│  📎 引用来源：某市智慧交通管理平台建设项目方案（第12-15页）│
│  ✅ AI自检：本章内容满足招标文件技术评分要求          │
│                                                   │
│  操作选项：                                        │
│  [✓ 采纳]  [↻ 重新生成]  [✎ 手动编辑]  [📋 查看差异]  │
│                                                   │
│  进度：3/8 章已完成  ████████░░░░  预估剩余 8 分钟   │
│  [⏸ 暂停]                                        │
└─────────────────────────────────────────────────┘
```

**新增交互：**
- **采纳**：确认使用当前生成内容，进入下一章
- **重新生成**：重新生成当前章节，显示新旧版本对比
- **手动编辑**：切换到编辑模式，用户可直接修改内容
- **查看差异**：对比本次生成与上次生成的差异（如有）
- **版本对比**：重新生成时，左右分栏显示新旧版本，用户可选择保留部分内容

### 2.2 技术标/商务标分离场景（MVP后规划）

#### 问题
实际投标中，技术标和商务标经常是分开的文件，有时还搭配工程量清单、图纸等附件。

#### 解决方案

**新建标书流程增强：**

```
Step 1: 项目信息录入
  ├── 标书名称
  ├── 关联项目
  ├── 上传招标文件
  └── 【新增】标书类型选择：
      ├── 综合标书（默认）- 技术标+商务标合一
      ├── 技术标 + 商务标（分离生成）
      └── 自定义组合
          ├── ☑ 技术标
          ├── ☑ 商务标
          ├── ☑ 工程量清单（报价表）
          └── ☑ 其他附件

Step 2-4: [同现有流程]

Step 5: AI逐章生成
  ├── 【新增】如果选择了分离模式，分别生成各标书
  ├── 技术标生成：侧重技术方案、实施方案
  ├── 商务标生成：侧重资质、业绩、报价
  └── 工程量清单：基于招标文件中的工程量清单要求生成

Step 6: 标书编辑器
  ├── 【新增】多标书标签页切换
  │   ├── [技术标] [商务标] [工程量清单]
  │   └── 每个标签页独立编辑
  └── 【新增】附件管理
      ├── 上传图纸、资质扫描件等
      └── 附件与标书章节关联

Step 7: 导出提交
  ├── 【新增】分别导出或合并导出
  │   ├── 分别导出：技术标.docx + 商务标.docx
  │   └── 合并导出：投标文件全套.zip
  └── 【新增】电子标书格式（如需要）
```

**MVP版本限制：**
- MVP版本保持现有的"综合标书"模式
- 标书类型选择入口预留，但选择后提示"该功能将在后续版本支持"
- 附件管理功能在MVP版本支持基础上传

## 三、合规检查 - 重新设计

### 3.1 问题分析

当前合规检查模块存在以下问题：
1. **缺少文件上传入口**：没有上传招标文件和投标文件的入口
2. **逻辑混乱**：检查流程不清晰，用户不知道从哪开始
3. **与标书生成模块脱节**：应该支持从标书生成模块直接传入文件

### 3.2 重新设计方案

**合规检查模块重新设计为三步流程：**

```
Step 1: 文件准备
├── 上传投标文件（必填）
│   ├── 支持 PDF/Word 格式
│   └── 拖拽上传区域
├── 上传招标文件（必填）
│   ├── 支持 PDF/Word 格式
│   └── 【智能匹配】如果该项目已有关联招标文件，自动带入
├── 从标书生成模块直接跳转
│   └── 自动带入投标文件 + 关联的招标文件
└── [开始检查]

Step 2: 检查配置（可选）
├── 检查范围
│   ├── 全文检查（默认）
│   └── 指定章节检查
├── 检查层级（四重校验）
│   ├── ☑ 第一层：结构化规则校验（默认开启）
│   ├── ☑ 第二层：语义一致性校验（默认开启）
│   ├── ☑ 第三层：废标风险校验（默认开启）
│   └── ☐ 第四层：评分优化建议（默认关闭，AI推理耗时较长）
├── 自定义规则
│   └── 添加企业内部合规要求
└── [开始检查]

Step 3: 检查结果
├── 评分概览（环形图 + 统计数字）
├── 检查结果标签页：
│   ├── 资质要求（第一层+第三层）
│   ├── 格式规范（第一层）
│   ├── 评分标准（第四层）
│   ├── 废标条款（第三层）- 红色高亮
│   └── 语义一致性（第二层）
├── 检查项列表
│   ├── 通过/警告/失败 三级状态
│   ├── 展开查看详细说明
│   ├── AI修复建议
│   ├── [跳转修复] → 打开编辑器定位到对应位置
│   └── [一键修复] → AI自动修复简单问题
└── [导出检查报告]
```

**关键交互改进：**
1. **文件上传区**：页面顶部明确展示两个上传区域（投标文件 + 招标文件）
2. **从标书生成跳转**：在标书编辑器和导出页面增加"合规检查"按钮，点击后自动带入文件
3. **检查进度**：检查过程中展示进度条和当前检查层级
4. **结果联动**：检查结果中每个问题项都有"跳转修复"和"一键修复"按钮

## 四、项目管理 - 迭代更新

### 4.1 看板交互增强

#### 问题
- 卡片不支持拖拽切换状态
- 无法修改卡片中的信息
- 缺少内容详情页

#### 解决方案

**看板拖拽交互：**
- 卡片支持拖拽到不同列（商机跟进 → 标书制作 → 投标中 → 已结果）
- 拖拽时显示放置指示器
- 拖拽完成后弹出确认提示（可选）
- 拖拽操作记录到操作日志

**卡片信息编辑：**
- 点击卡片标题旁的编辑图标，进入行内编辑模式
- 可编辑字段：项目名称、金额、截止日期、优先级、负责人
- 编辑完成后自动保存

**项目详情页增强：**
```
项目详情页
├── 基本信息卡片（可编辑）
│   ├── 项目名称、招标单位、预算金额
│   ├── 截止日期、负责人、优先级
│   └── [编辑] [删除] 按钮
├── 里程碑时间线（可添加/编辑/删除）
│   ├── 项目创建 → 标书制作 → 提交投标 → 开标评标 → 中标/未中标
│   └── 每个节点可设置日期和备注
├── 关联标书列表
│   ├── 标书名称、状态、创建时间
│   └── [编辑] [查看] 操作
├── 团队成员（可添加/移除）
│   └── 成员头像、姓名、角色
├── 操作日志（新增）
│   ├── 记录所有关键操作（创建、状态变更、编辑等）
│   └── 操作人、操作时间、操作内容
└── 中标项目 → [创建成本项目] 按钮
```

## 五、成本管理 - 架构调整

### 5.1 问题
- 顶部统计卡片（总成本/总收入/利润率/项目数）缺乏实际意义，数据来源不明确
- 缺少单项目维度的成本分析
- 没有成本知识库沉淀机制

### 5.2 重新设计方案

**成本管理模块重新设计：**

```
成本管理
├── 项目成本列表（主页面）
│   ├── 项目名称
│   ├── 中标金额
│   ├── 实际成本
│   ├── 利润率
│   ├── 状态（进行中/已结项）
│   └── [查看详情] [编辑]
│
├── 单项目成本分析（点击项目进入）
│   ├── 项目基本信息（项目名、中标金额、负责人）
│   ├── 成本构成图表（饼图 + 柱状图）
│   │   ├── 人力成本
│   │   ├── 材料成本
│   │   ├── 设备成本
│   │   └── 其他成本（差旅、管理等）
│   ├── 成本明细录入
│   │   ├── 按类别录入各项成本
│   │   ├── 支持按项目阶段分摊
│   │   └── 实际成本 vs 预算对比
│   ├── 利润分析
│   │   ├── 实际利润率
│   │   ├── 与行业平均对比
│   │   └── 成本优化建议
│   └── [导出成本报告]
│
└── 成本知识库（新增，MVP后）
    ├── 历史项目成本数据沉淀
    ├── 按项目类型分类（信息化工程/货物采购/建筑工程等）
    ├── 按地区分类
    ├── 成本参考数据（人力日单价、材料单价等）
    └── AI生成标书时自动引用成本数据
```

**MVP版本：**
- 主页面展示项目成本列表
- 点击进入单项目成本分析页
- 支持成本录入和图表展示
- 成本知识库功能在MVP后实现

## 六、团队协作 - 迭代更新

### 6.1 管理员权限体系

#### 问题
- 缺少管理员账号概念
- 没有模块级权限管控（如成本模块不应给普通投标员工查看）

#### 解决方案

**权限体系设计：**

```
角色定义：
├── 超级管理员（企业级）
│   ├── 所有模块完整权限
│   ├── 团队管理（邀请/移除成员）
│   ├── 角色权限配置
│   └── 系统设置
│
├── 部门管理员
│   ├── 标讯大厅、标书生成、合规检查、项目管理、知识库
│   ├── 成本管理（只读）
│   └── 团队管理（仅查看）
│
├── 项目经理
│   ├── 标讯大厅、标书生成、合规检查、项目管理
│   ├── 知识库（只读）
│   └── 成本管理（不可见）
│
├── 投标专员
│   ├── 标讯大厅（只读）
│   ├── 标书生成、合规检查
│   ├── 知识库（只读）
│   └── 项目管理（仅自己参与的项目）
│
└── 查看者
    └── 仅可查看被授权的项目和标书
```

**模块级权限管控：**
- 每个模块可独立设置可见性（可见/隐藏）
- 每个模块可独立设置操作权限（完整/只读/无权限）
- 无权限的模块在导航栏中隐藏或置灰

**权限配置入口：**
- 在团队协作 → 成员管理中，点击成员的"编辑"按钮
- 弹出权限配置面板
- 可选择预设角色或自定义权限

### 6.2 交互深度增强

- 审批流程增加审批链配置（多级审批）
- 通知中心增加通知类型筛选
- 成员管理增加批量操作（批量修改角色、批量移除）

## 七、知识库 - 迭代更新

### 7.1 问题
- 很多功能有界面但缺少完整的交互逻辑
- 有入口但缺少配置/管理界面
- 有按钮但缺少完整的业务流转

### 7.2 交互逻辑补全

**分类详情页增强：**
```
分类详情页（以"企业资质"为例）
├── 搜索栏 + 筛选（按类型、有效期、上传时间）
├── 文档列表
│   ├── 文件名、类型、上传时间、操作人
│   ├── AI智能标签（自动打标）
│   ├── 有效期倒计时（资质类文档）
│   ├── [预览] [编辑标签] [下载] [删除]
│   └── 批量操作：批量移动、批量删除、批量导出
├── 文档预览弹窗
│   ├── PDF/Word 文档在线预览
│   ├── AI提取的关键信息摘要
│   └── 被引用记录（哪些标书引用了此文档）
└── [上传文档] 按钮
```

**文档上传流程增强：**
```
上传文档
├── 拖拽上传 / 点击上传
├── AI自动解析
│   ├── 自动识别文档类型（资质/案例/方案/人员/模板）
│   ├── 自动提取关键信息
│   │   ├── 资质类：资质名称、有效期、发证机关
│   │   ├── 案例类：项目名称、合同金额、交付时间
│   │   └── 方案类：方案类型、适用行业
│   └── 自动生成AI智能标签
├── 用户确认/补充
│   ├── 确认AI识别的类型和关键信息
│   ├── 手动补充标签
│   └── 选择存储分类
└── 上传完成 → 显示在最近更新列表
```

**业务闭环补全：**
1. **标书生成引用追踪**：在知识库文档详情中，显示"被哪些标书引用"
2. **中标案例自动回流**：项目中标后，关联的标书自动归档到"业绩案例"
3. **资质到期提醒**：资质类文档到期前30天自动提醒，同步到工作台和通知中心
4. **知识库使用统计**：展示各分类文档数量趋势、被引用次数排行

## 八、待讨论事项（延后处理）

### 8.1 导航结构优化

当前导航栏分为8个模块：工作台、标讯大厅、标书生成、合规检查、项目管理、成本管理、知识库、团队协作。

**待讨论问题：**
1. 8个导航项是否过多？用户是否会感到混乱？
2. "合规检查"是否应该作为"标书生成"的子功能？
3. "成本管理"是否应该作为"项目管理"中标后的子功能？
