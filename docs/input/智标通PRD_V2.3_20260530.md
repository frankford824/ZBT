## 一、产品概述（沿用V2.2，无变更）

### 1.1 产品定位
面向企业投标团队（5-20人）的 B2B 智能标书生成平台。

### 1.2 核心价值主张
- 提效：将 3-5 天的标书编制周期压缩至 1-2 天
- 降险：AI 合规检查降低废标率
- 沉淀：企业知识资产持续积累

### 1.3 核心功能模块（8个）
1. 工作台
2. 标讯大厅
3. 标书生成
4. 合规检查
5. 项目管理
6. 成本管理
7. 知识库
8. 团队协作

## 二、V2.3 变更详情

### 2.1 项目管理 - 交互优化

#### 2.1.1 里程碑编辑弹窗（修复）

**变更类型**：交互修复

**变更前**：使用原生 `prompt()` 进行编辑，用户体验差

**变更后**：自定义模态弹窗，包含：
- **状态选择**：下拉框（待开始/进行中/已完成）
- **日期选择**：日期选择器
- **备注输入**：多行文本框
- **操作按钮**：保存、取消

**交互流程**：
1. 用户点击里程碑节点
2. 弹出编辑弹窗，预填充当前值
3. 用户修改状态、日期、备注
4. 点击保存后更新节点显示

#### 2.1.2 看板状态标签切换（新增）

**变更类型**：新增交互功能

**功能描述**：点击看板卡片上的状态标签，可循环切换项目状态

**状态流转**：
```
进行中 → 标书制作 → 合规审核 → 投标中 → 已结果 → 进行中
```

**视觉反馈**：
- 切换时标签颜色/文字即时更新
- 可选：添加切换动画效果

**实现要点**：
- 给状态标签添加 `onclick` 事件
- 维护状态流转数组
- 更新卡片 `data-status` 属性

#### 2.1.3 看板卡片名称编辑（优化）

**变更类型**：交互优化

**变更前**：需点击编辑图标触发编辑

**变更后**：
- 点击编辑图标可编辑（保留）
- **新增**：点击项目名称本身也可触发编辑

**实现要点**：
- 给 `.proj-card-name` 元素添加 `onclick` 事件
- 复用现有的 `enableCardEdit` 逻辑
- 注意阻止事件冒泡，避免触发卡片点击

## 三、侧边栏导航重构（V2.3 核心变更）

### 3.1 层级分组

**分组方案：按业务阶段**

| 分组名称 | 图标 | 包含菜单 | 说明 |
|---------|-----|---------|-----|
| **📊 概览** | fa-gauge-high | 工作台 | 统一入口，展示工作全貌 |
| **🔍 投标准备** | fa-magnifying-glass | 标讯大厅、标书生成 | 获取招标信息→生成标书 |
| **✅ 投标管控** | fa-clipboard-check | 合规检查、项目管理 | 质量把控+进度跟踪 |
| **💼 企业管理** | fa-building | 成本管理、知识库、团队协作 | 中标后管理和知识沉淀 |

**视觉样式**：
- 分组标题：小号灰色文字，全大写，带图标
- 分组间距：组间 16px，组内 4px
- 当前选中项：高亮显示

### 3.2 子菜单

**标书生成子菜单**：
- 新建标书
- 我的标书
- 模板库

**知识库子菜单**：
- 文档库
- 模板库
- 标签管理

**交互行为**：
- 点击父菜单展开/收起子菜单
- 展开时父菜单图标旋转 90°
- 子菜单项缩进 24px
- 当前子菜单项高亮

### 3.3 权限控制

**角色权限矩阵**：

| 菜单/角色 | 管理员 | 项目经理 | 普通成员 |
|----------|-------|---------|---------|
| 📊 概览 | ✅ | ✅ | ✅ |
| 🔍 标讯大厅 | ✅ | ✅ | ✅ |
| 🔍 标书生成 | ✅ | ✅ | ✅ |
| ✅ 合规检查 | ✅ | ✅ | ✅ |
| ✅ 项目管理 | ✅ | ✅ | ✅ |
| 💼 成本管理 | ✅ | ✅ | ❌ |
| 💼 知识库 | ✅ | ✅ | ✅ |
| 💼 团队协作 | ✅ | ❌ | ❌ |

**实现说明**：
- 无权限的菜单项隐藏不显示
- 权限变更后侧边栏实时更新
- 当前用户角色存储在全局状态

### 3.4 可折叠

**展开状态**（默认）：
- 侧边栏宽度：240px
- 显示完整菜单文字
- 显示分组标题

**收起状态**：
- 侧边栏宽度：64px
- 仅显示图标
- 分组标题隐藏
- 鼠标悬停显示 Tooltip

**切换方式**：
- 顶部固定切换按钮
- 点击后平滑过渡动画（300ms）
- 状态持久化（localStorage）

**收起状态下的子菜单**：
- 鼠标悬停父菜单时，右侧弹出子菜单面板
- 面板宽度：200px
- 点击子菜单项后自动收起
