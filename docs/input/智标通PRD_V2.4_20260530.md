## 一、产品概述（沿用V2.3，无变更）

### 1.1 产品定位
面向企业投标团队（5-20人）的 B2B 智能标书生成平台。

### 1.2 核心价值主张
- 提效：将 3-5 天的标书编制周期压缩至 1-2 天
- 降险：AI 合规检查降低废标率
- 沉淀：企业知识资产持续积累

### 1.3 核心功能模块（8个）
1. 工作台
2. 标讯大厅
3. 标书生成
4. 合规检查
5. 项目管理
6. 成本管理
7. 知识库
8. 团队协作

## 二、V2.4 变更详情

### 2.1 标书生成模块 - 子页面拆分

#### 2.1.1 模块架构调整

**变更类型**：功能架构优化

**变更前**：标书生成为单一页面，包含7步向导流程

**变更后**：拆分为3个独立子页面，通过侧边栏子菜单导航

| 子页面 | 页面ID | 功能定位 | 入口 |
|-------|--------|---------|------|
| 新建标书 | page-generate-new | 快速开始新的标书生成 | 侧边栏 > 投标准备 > 新建标书 |
| 我的标书 | page-generate-list | 管理所有已创建的标书 | 侧边栏 > 投标准备 > 我的标书 |
| 模板库 | page-generate-templates | 浏览和使用标书模板 | 侧边栏 > 投标准备 > 模板库 |

#### 2.1.2 新建标书页面 (page-generate-new)

**功能描述**：
提供标书生成的入口页面，用户填写项目基本信息后，可选择进入7步向导流程或使用模板快速生成。

**页面布局**：
```
+------------------+  +------------------+
|   页面标题        |  |                  |
|   新建标书        |  |   帮助提示卡片    |
+------------------+  |   - 生成提示      |
                      |   - 预计时间      |
+------------------+  |                  |
|   项目基本信息    |  |                  |
|   - 项目名称 *    |  |                  |
|   - 招标单位      |  +------------------+
|   - 投标截止日期  |
|   - 项目预算      |
+------------------+
|   标书类型选择    |
|   [综合标书]      |
|   [分离标书]      |
+------------------+
|   [取消] [开始生成]|
+------------------+
```

**交互流程**：
1. 用户填写项目基本信息（项目名称为必填）
2. 选择标书类型（综合/分离）
3. 点击"开始生成"进入7步向导流程
4. 或点击"取消"返回我的标书列表

**数据字段**：
| 字段 | 类型 | 必填 | 说明 |
|-----|------|-----|------|
| 项目名称 | 文本 | 是 | 标书标题 |
| 招标单位 | 文本 | 否 | 招标方名称 |
| 投标截止日期 | 日期 | 否 | 用于提醒 |
| 项目预算 | 金额 | 否 | 预算金额 |
| 标书类型 | 单选 | 是 | 综合/分离 |

#### 2.1.3 我的标书页面 (page-generate-list)

**功能描述**：
展示用户创建的所有标书，支持状态筛选、搜索、排序、批量操作。

**页面布局**：
```
+------------------+
|   页面标题        |
|   我的标书        |
+------------------+
| [全部][编制中][审核中][已完成] |
+------------------+
| 搜索... | 筛选 ▼ |  [+ 新建标书] |
+------------------+
| ☑ | 标书名称    | 项目 | 类型 | 状态 | 进度 | 操作 |
|---|-------------|------|------|------|------|------|
| ☐ | xxx技术标   | xxx  | 技术 | 编制 | 60%  | 编辑 |
| ☐ | xxx商务标   | xxx  | 商务 | 审核 | 80%  | 编辑 |
+------------------+
| 共12条  1 2 3 ... 下一页 |
+------------------+
```

**功能特性**：
- **统计卡片**：展示全部/编制中/审核中/已完成数量
- **搜索**：支持按标书名称、项目名称搜索
- **筛选**：按状态、类型、时间筛选
- **列表展示**：标书名称、关联项目、标书类型、状态、进度、操作
- **分页**：每页10条，支持跳转
- **批量操作**：选中后可批量导出、删除

**状态定义**：
| 状态 | 说明 |
|-----|------|
| 编制中 | 正在生成或编辑标书内容 |
| 审核中 | 已提交审核，等待审批 |
| 已完成 | 标书已最终确认，可导出 |

#### 2.1.4 标书模板库页面 (page-generate-templates)

**功能描述**：
提供标书模板浏览、预览、使用功能，帮助用户快速创建标书。

**页面布局**：
```
+------------------+
|   页面标题        |
|   标书模板库      |
+------------------+
| [全部][IT信息化][工程建设][政府采购][我的模板] |
+------------------+
+--------+ +--------+ +--------+
| 模板卡片 | | 模板卡片 | | 模板卡片 |
| [预览]  | | [预览]  | | [预览]  |
| [使用]  | | [使用]  | | [使用]  |
+--------+ +--------+ +--------+
```

**模板卡片信息**：
- 模板预览图/图标
- 模板名称
- 模板描述
- 使用次数

- 操作按钮：预览、使用

**分类**：

### 2.2 知识库模块 - 子页面拆分

#### 2.2.1 模块架构调整

**变更类型**：功能架构优化

**变更前**：知识库为单一页面，包含文档列表

**变更后**：拆分为3个独立子页面，通过侧边栏子菜单导航

| 子页面 | 页面ID | 功能定位 | 入口 |

| 标签管理 | page-knowledge-tags | 文档标签管理 | 侧边栏 > 企业管理 > 标签管理 |

#### 2.2.2 文档库页面 (page-knowledge-docs)

**功能描述**：
企业文档的统一管理中心，支持文档上传、下载、分类、搜索、标签管理。

**页面布局**：
```
+------------------+---------------------------+
|   文档分类        |   页面标题：文档库         |
|                  |   搜索...  [筛选] [上传]   |
| [全部文档] 156   |                           |
| [资质证书]  23   | +-----------------------+ |
| [项目案例]  45   | | ☑ | 文档名 | 大小 | 日期 | 操作 |
| [技术方案]  67   | |---|--------|------|------|------|
| [合同模板]  21   | | ☐ | xxx.pdf| 2.5M | 5-20 | 下载 |
|                  | | ☐ | xxx.doc| 1.2M | 5-19 | 下载 |
| [+ 新建分类]     | +-----------------------+ |
+------------------+---------------------------+
```

**功能特性**：
- **分类管理**：左侧分类树，支持新建/编辑/删除分类
- **文档列表**：展示文档名称、大小、上传时间、上传者、标签
- **搜索**：支持按文档名、标签搜索
- **筛选**：按文件类型、上传时间、标签筛选
- **批量操作**：批量下载、移动、删除
- **上传**：支持拖拽上传、文件夹上传

**支持的文件类型**：
- 文档：PDF、Word（doc/docx）、Excel（xls/xlsx）、PPT（ppt/pptx）
- 图片：JPG、PNG、GIF
- 压缩包：ZIP、RAR

#### 2.2.3 模板库页面 (page-knowledge-templates)

**功能描述**：
与标书模板库区分，用于管理企业内部文档模板（如方案模板、报告模板、合同模板等）。

**页面布局**：
```
+------------------+
|   页面标题        |
|   文档模板库      |
+------------------+
| [全部][方案模板][报告模板][合同模板][制度模板] |
+------------------+
| 模板名称 | 分类 | 版本 | 更新时间 | 使用次数 | 操作 |
|----------|------|------|----------|----------|------|
| xxx.docx | 方案 | v3.0 | 2026-05-25 | 89次 | 预览 编辑 下载 |
+------------------+
```

**功能特性**：
- 模板列表展示（表格形式）
- 分类筛选
- 版本管理
- 使用统计
- 操作：预览、编辑、下载

#### 2.2.4 标签管理页面 (page-knowledge-tags)

**功能描述**：
文档标签的集中管理中心，支持标签的创建、编辑、删除，以及查看标签关联的文档。

**页面布局**：
```
+------------------+---------------------------+
|   [+ 新建标签]    |   标签详情：资质证书       |
|                  |   共关联 23 个文档         |
| ● 资质证书  23   |   [编辑] [删除]            |
| ● 技术方案  67   |                           |
| ● 项目案例  45   | +-----------------------+ |
|                  | | 关联文档列表            | |
|                  | | - xxx.pdf              | |
|                  | | - xxx.doc              | |
|                  | +-----------------------+ |
+------------------+---------------------------+
```

**功能特性**：
- **标签列表**：左侧展示所有标签，显示标签颜色和关联文档数
- **标签详情**：右侧展示选中标签的详细信息
- **新建标签**：设置标签名称、颜色
- **编辑标签**：修改标签信息
- **删除标签**：删除标签（需确认，可保留或移除文档关联）
- **关联文档**：查看和管理标签关联的文档

**标签属性**：
| 属性 | 说明 |
|-----|------|
| 标签名称 | 唯一标识，如"资质证书" |
| 标签颜色 | 用于视觉区分，如蓝色、绿色、橙色 |
| 关联文档数 | 使用该标签的文档数量 |
